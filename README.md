# OMORO

『水曜日のダウソタウソ』の印象的な場面を、短いセリフと解説でたどる非公式ファンサイトです。6つの特設ページと、文字で前後を追う操作、端末内の保存、検索、ランダム表示、OMORO LABを備えています。

OMORO LABでは、セリフの自動送り、発言者を当てる6問クイズ、テーマとサイズを選べるPNG画像カードを使えます。クイズと画像生成はブラウザ内で完結します。特設ページの「カードにする」から、そのセリフを選択した状態で開けます。

## ローカルで見る

`node scripts/build-pages.mjs` で6つの特設ページと共有データを生成します。そのあと `dist` を静的サイトとして配信してください。外部依存はありません。各ページのルート相対リンクを使うため、サイトのルートから配信します。

## 構成

- `dist/index.html` — ページ本文
- `dist/styles.css` — レイアウトとデザイン
- `dist/app.js` — 名場面の切り替え
- `data/moments.json` — 6つのセリフと解説の元データ
- `scripts/build-pages.mjs` — 特設ページの生成
- `dist/detail.css`, `dist/detail.js` — 特設ページの表示と操作
- `dist/lab/` — セリフ送り、クイズ、画像カードの画面と操作

映像と音声は使用していません。番組・出演者とは関係のない非公式サイトです。

# OMORO v2

『水曜日のダウソタウソ』の印象的な場面を、短いセリフと解説でたどる**非公式ファンサイト**。v2 で 3D・シェーダー・スクロール演出を全面導入しました。

公開URL: https://sc8z35a-collab.github.io/omoro/

## ページと機能

| ページ | 内容 |
| --- | --- |
| `/` ホーム | WebGL ヒーロー（14,000粒のパーティクルがセリフの形にモーフ、マウスで反発、スポットライト、グリッド床、ブルーム）／横スクロールのホログラムカード／写真クロスフェードのステージプレイヤー（自動送り・反応ボタン）／会話の連鎖マップ（SVG線をスクロールで描画）／声量×間のバブルチャート／タグ＋検索のアーカイブ／保存リスト／「間」のピン留め演出 |
| `/gallery/` | 3Dギャラリー：鏡面の床とネオンアーチのホールに6枚のカード。Ring / Helix / Wall レイアウト、ドラッグで回転、ホイールで移動、クリックで寄る、ホログラムシェーダー |
| `/moments/<slug>/` ×6 | 写真に RGB ずれの液体リップルをかける WebGL ヒーロー、スクロールで進むビート、解説カード、反応ボタン、シェア、前後ナビ |
| `/lab/` | ①3Dでめくれるセリフ送り ②発言者クイズ（タイムアタック・ベストスコア） ③画像カードメーカー（5テーマ×3サイズ、PNG保存・共有） ④距離シミュレーター ⑤間チャレンジ（1.8秒を狙う） ⑥温度差変換（大声→半角カナの小声） |
| `/credits/`, `404` | 写真クレジット、404ページ |

共通：ローダー、ページ遷移カーテン、慣性スクロール（Lenis）、カスタムカーソル、マグネティックボタン、⌘K / `/` で開くコマンドパレット検索、`?` でショートカット一覧、フルスクリーンメニュー。`prefers-reduced-motion` のときはアニメーションを止め、WebGL が使えないときは画像にフォールバックします。保存・反応・スコアはこの端末の localStorage にだけ残ります。

## 開発

```bash
npm install
npm run dev        # 特設ページを生成してから Vite を起動 (http://localhost:5173)
npm run build      # .build/ に出力（ルート配信用）
npm run publish    # /omoro/ 用にビルドしてリポジトリ直下へ配置（GitHub Pages 用）
```

- `data/moments.json` — 6つのセリフのデータ（元データはすべてここ）
- `scripts/build-pages.mjs` — `site/moments/*/index.html` を生成
- `site/` — Vite のルート（`partials/` の `<!--#include x -->` と `{{base}}` はビルド時に展開）
- `site/src/js/gl/` — three.js のシーン（hero / gallery / ripple / card texture）
- `scripts/process-images.mjs`, `scripts/og.mjs` — 画像の最適化と OGP 画像

### デプロイ

GitHub Pages は **main ブランチのルート** を配信する設定です。`npm run publish` でビルド結果（`index.html`, `assets/`, `img/` など、`.published.json` に一覧）をリポジトリ直下に置き、main にマージすると反映されます。`.nojekyll` で Jekyll 処理を止めています。

## 素材とことわり

番組の映像・音声・写真は使っていません。場面のイメージ写真はパブリックドメイン / CC0 素材を加工して使っています（出典は `/credits/`）。番組・出演者・放送局とは関係のない非公式サイトです。

- 方法: 全ソースのコードレビュー + Playwright(Chromium/SwiftShader WebGL)による実機検証とスクリーンショット確認
  （デスクトップ 1440×900 / 1000×900 / 800×900、モバイル 390×844、`prefers-reduced-motion`、`?nogl`）
